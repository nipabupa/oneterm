| 组件      | Linux               | Macos               | Windows             |
| --        | --                  | --                  | --                  |

| Terminal  | Wezterm             | Wezterm             | Wezterm             |
| Font      | wezterm内置nerdfont | wezterm内置nerdfont | wezterm内置nerdfont |
| Editor    | neovim              | neovim              | neovim              |

- 可自行配置其他nerdfont字体，参考wezterm或其他终端配置文档
