# 安装配置

## 总体配置

| 组件     | Linux               | Windows                      |
| --       | --                  | --                           |
| Shell    | fish                | powershell                   |
| Terminal | ghostty             | WindowsTerminal              |
| Font     | ghostty内置nerdfont | DejavuSansNerdFont(个人喜好) |
| Editor   | neovim              | neovim                       |
| 窗口管理 | hyprland            | glazewm(不用也行)            |

普通显示器可以考虑Niri，无限滚动显示的东西更多些，但是大显示器建议hyprland，信息密度更高。

## 终端工具

| 工具     | 说明                                                   |
| --       | --                                                     |
| fd       | find替代，高性能文件搜索                               |
| ripgrep  | grep，高性能文本搜索, 也是mini.nvim配置依赖            |
| fzf      | 模糊搜索, 终端下好用，对应也有neovim的插件，看个人喜好 |
| sharship | prompt美化, 啥shell都好使                              |
| eza      | ls美化                                                 |
| yazi     | 文件管理, 无敌                                         |
| lazygit  | git工具                                                |

## Neovim

整体思路就是使用最小的插件集完成所需配置，不整花里胡哨，兼顾性能与美观
